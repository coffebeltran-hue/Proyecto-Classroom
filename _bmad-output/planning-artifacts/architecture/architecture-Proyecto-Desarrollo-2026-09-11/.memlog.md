- (decision) AD-4 ADOPTED by Juan: each academic evaluation references an exact Submission revision; its draft remains attached. Resubmission creates an independent revision, visible to teacher/student, without invalidating existing evaluations, inheriting a grade or triggering regrading. Existing official publication remains valid for its evaluated revision. Teacher explicitly creates a new evaluation/draft for a new revision; only explicit publication replaces the current official grade. Previous publication evidence is never silently overwritten and publication audit history is retained permanently. Normal deadline/extension rules apply regardless of prior grading. Binds submissions, evaluations, drafts, publications, audit and UX.
- (decision) AD-5 ADOPTED by Juan: backend UTC durable receipt time is authoritative; client time and commit date are not. Before receipt acknowledgment persist actor, assignment/acceptance, requested SHA, received time, effective deadline and policy version. Received at or before deadline is candidate on-time; processing delay cannot automatically make it late. Confirm only after authorization and revision evidence validation; insufficient evidence needs review; invalid/unauthorized/ineligible requests never confirm. No fabricated receipt after failed persistence. Teacher exceptions are explicit audited academic decisions without altering original timestamps. Same idempotency key recovers same operation; another SHA is a new operation. Preserve original deadline/policy, audit later reclassification. Separate receipt/validation lifecycle from academic classification; received, validating, confirmed, needs_review, rejected are example labels, not a mandated single field. Binds submissions, deadlines, persistence, integration, audit and UX.
- (decision) AD-6 ADOPTED by Juan: every confirmed Submission revision creates a preservation operation for its exact SHA, never substitute branch head. No all-push snapshots or full Git history in MVP. Private object storage outside PostgreSQL; DB records revision, SHA, location, cryptographic digest, size, capture time, preservation status, origin and mechanism version where relevant. Preservation status independent from confirmed submission and punctuality; failures visible to authorized staff and retryable, never invalidate original receipt. API/preservation worker never execute archived content. Tenant/course/student/role authorization; audit administrative/exceptional access. Explicit completeness manifest for LFS, submodules, external files/dependencies. Distinguish receipt, content, evaluation and publication evidence; later capture cannot prove earlier availability. Code retention permanence NOT approved; retention, quotas, deletion, course closure and institutional obligations require separate decision.

- (decision) AD-8 ADOPTED by Juan: each published assignment version has positive maximum; academic score and maximum accept up to two decimals, exact decimal backend representation, 0<=score<=maximum. Reject excess precision without silent rounding. Ungraded, pending, incomplete draft and zero distinct; absent evaluation never becomes zero. Official publication snapshots score, maximum, scale/config version, evaluation, exact Submission revision, publisher and timestamp. Later scale changes never reinterpret historical evaluations/drafts/publications; if supported, changes require explicit versioned audited teacher operation. No automatic mass regrading. Percentage derived only score/maximum*100 with decimal half-up rounding to two decimals, not a second persisted official grade. MVP excludes extra credit, over-max scores, letter grades, automatic conversions, weighted course averages and complex institutional policies. Future policies preserve historical meaning. Withdrawal without replacement remains separate pending decision.
- (decision) AD-9 ADOPTED by Juan: authorized teacher may explicitly withdraw exact current official publication with mandatory reason. Append immutable withdrawal with publication, teacher, date, reason and audit; original publication permanently preserves score/max/scale/evaluation/submission/publisher/date. After withdrawal no current grade, no zero or previous-grade restoration; evaluations/drafts/submission/evidence unchanged. New explicit publication required even same value. Compare expected current publication atomically; if B replaces A, withdrawal targeting A conflicts and must not withdraw B. Idempotency replay returns original outcome. Withdrawal never shortens evidence retention extended by publication. Distinguish ungraded/published/withdrawn and independent newer-submission indicator. Student-safe explanation separate from internal administrative notes. Complete immutable publication-withdrawal-publication history.
